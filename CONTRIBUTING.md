# Contributing to Project Atlas

Project Atlas is a personal infrastructure portfolio, but corrections, documentation improvements, and constructive suggestions are welcome.

## Documentation Expectations

Every technical change should include:

- Purpose
- Prerequisites
- Implementation steps
- Verification
- Screenshots where useful
- Troubleshooting notes
- Security considerations
- Lessons learned

## Branch and Commit Style

Use a short branch name:

```text
docs/storage-raid5
feat/docker-media-stack
fix/network-vlan-table
```

Use clear commit messages:

```text
docs(storage): add RAID 5 troubleshooting case study
feat(docker): deploy Portainer management service
fix(proxmox): correct media storage mount path
chore(repo): polish Project Atlas landing page
```

## Pull Request Checklist

- Internal links work
- Commands were verified
- Screenshots contain no credentials or personal information
- Placeholder text is clearly marked
- Roadmap and journal were updated where appropriate
