# Problems Encountered

- External storage disconnect
- Boot delays
- VirtIOFS directory mapping failure
- USB-to-eSATA bridge recovery
- Community rack ears required modification

---

# Lessons Learned

- Always use nofail for removable storage.
- Verify storage before VM startup.
- Test every reboot.
- Document configuration changes immediately.
- Validate community STL dimensions before printing.
