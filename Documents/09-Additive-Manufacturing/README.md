# Phase 09 — Additive Manufacturing

## Purpose

Use the Bambu Lab P1S and AMS to create practical parts for Project Atlas.

## Planned Uses

- Mini-PC mounts
- Rack ears and adapters
- Cable guides
- Label holders
- Drive and accessory organizers
- Tool holders
- Airflow accessories
- Custom brackets

## Documentation Standard

For each useful print, record:

- Model source or original design
- License
- Filament type
- Nozzle size
- Layer height
- Supports
- Infill
- Print time
- Fit adjustments
- Final installation photo
