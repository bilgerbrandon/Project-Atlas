# Rack Build

## Purpose

Create a clean, maintainable physical home for Project Atlas.

## Planned Layout

```text
Top
├── Patch panel
├── Cable manager
├── Managed switch
├── Mini-PC shelf
├── Storage enclosure shelf
├── Future node shelf
└── UPS / power distribution
Bottom
```

## Build Requirements

- Keep heavy components low
- Maintain airflow around mini PCs and storage
- Separate power and data where practical
- Use short patch cables
- Label both ends of every cable
- Leave room for future expansion
- Secure the rack against accidental tipping
