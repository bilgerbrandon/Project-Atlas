# Wazuh

## Status

Planned.

## Purpose

Add centralized security monitoring, log analysis, file-integrity monitoring, and endpoint visibility to Project Atlas.

## Initial Scope

- Proxmox host
- Ubuntu Docker VM
- Administrative Mac where supported and appropriate
- Authentication events
- Configuration changes
- Important system logs

## Success Criteria

- Agents report consistently
- Alerts are understandable
- High-noise rules are tuned
- Critical events produce a useful notification
- Installation and rollback procedures are documented
