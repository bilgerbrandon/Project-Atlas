# Phase 08 — Monitoring and Security

## Goal

Provide useful visibility into host health, storage, containers, service uptime, logs, and security events.

## Planned Components

- Wazuh
- Uptime monitoring
- Metrics collection
- Grafana dashboards
- Centralized logs
- Storage health alerts
- Proxmox notifications
- Docker health checks

## Monitoring Priorities

1. Host availability
2. RAID and disk health
3. Storage capacity
4. VM and container state
5. Backup success
6. High CPU, memory, or temperature
7. Authentication failures
8. Unexpected exposed ports

## Documentation Requirements

- What is monitored
- Alert threshold
- Alert destination
- Expected response
- False-positive notes
- Recovery procedure
